title=mail-hantong AI 대화

notice=설정한 계정의 메일 도구가 연결됩니다. 요청한 메일 정보는 선택한 AI 제공자에 전달될 수 있으며 받은편지함 전체를 한꺼번에 올리지는 않습니다. 발송·휴지통 이동은 터미널 확인이 필요합니다. 명령 안내는 /help를 입력하세요.
prompt=나
reply=AI
browser=공식 제공자 창에서 로그인을 완료하세요. Claude는 Console API 사용량 결제 로그인을 사용합니다.
ready=로그인했습니다.
missing=공식 제공자 CLI를 설치한 뒤 다시 실행하세요. Codex: https://developers.openai.com/codex/cli ; Claude: https://code.claude.com/docs/en/setup
subscription=Claude 앱 내 대화에는 Console/API 결제가 필요합니다. 이 앱은 claude.ai 구독 OAuth를 제공하지 않습니다. 공식 Claude CLI를 별도로 실행하거나 Console로 로그인하세요.
failed=AI 작업이 실패했습니다.
sandbox_unavailable=현재 Codex는 Windows에서 한통의 제한된 파일 접근을 지원하지 않습니다. 메일 도구 등록은 보존했으며, 파일 접근 범위를 넓히지 않고 대화를 중단했습니다.
login=먼저 이 제공자에 로그인하세요.
human=대화형 터미널이 필요합니다. 스크립트에서는 로그인 후 chat PROVIDER --prompt 내용을 사용하세요.
help_header=AI 대화 명령어:
help_help=/help — 이 명령어 목록을 표시합니다(제공자 호출 없음)
help_status=/status — 현재 제공자·모델·모드·fast·agent 상태를 표시합니다
help_provider=/provider PROVIDER — 제공자를 전환합니다. /provide도 같은 명령입니다. list로 선택지를 봅니다
help_model=/model [list|ID] — 모델 목록을 보거나 ID로 모델을 선택합니다
help_mode=/mode [light|med|high|ultra-high] — 모델의 추론 모드를 보거나 선택합니다
help_fast=/fast [on|off] — 지원되는 경우 빠른 응답 설정을 보거나 변경합니다
help_agent=/agent [on|off] — 이 세션의 메일 에이전트 도구 접근을 보거나 변경합니다
help_cli=/cli — AI 대화를 끝내고 기본 CLI로 돌아갑니다
help_quit=/quit — AI 대화를 끝냅니다
clean=새 제공자의 별도 설정에 따라 메일 도구를 연결했습니다. 이전 대화는 전달하지 않았습니다.
mail_setup=이 터미널에서 AI 메일 기능을 설정합니다. 선택한 제공자에 전달할 계정과 데이터를 확인하세요. 외부 MCP 권한과는 별개입니다.
mail_setup_failed=AI 메일 기능을 준비하지 못했습니다. 기존 계정 권한과 메일은 유지됩니다.
claude_native=이 터미널에서 공식 Claude Code를 시작합니다. 대화 기록은 Claude Code의 설정을 따르며 한통은 대화를 수집하지 않습니다. 안내를 확인하고 /exit를 입력하면 한통으로 돌아옵니다.
