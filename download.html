설치한 뒤에는

  1. 실행: hantong --version으로 버전을 확인하고 hantong --lang ko로 시작합니다.
  2. 계정 연결: Google 또는 일반 IMAP/SMTP 연결 안내를 따릅니다. 여러 계정은 기존 연결을 유지하며 추가합니다.
  3. 메일 이용: CLI 또는 통신풍 TUI에서 메일을 읽고 작성합니다. AI 연결은 선택 기능입니다.

Unix 압축 파일은 새 폴더에 풀고 sh install.sh를 실행합니다. Linux 서버에서는 최초 실행 시 1) headless passphrase를 선택하고, Core 재시작 시 터미널에서 금고를 잠금 해제합니다. macOS는 잠금 해제된 Keychain이 필요합니다.

업데이트는 hantong update로 진행합니다. 구버전 오류·문제 해결과 beta.22 검증 범위도 확인하세요.

파일 확인과 알려진 제한

SHA256SUMS로 다운로드한 파일을 확인하세요. 소스·빌드 정보·검증 범위는 GitHub 릴리스 원문에 있습니다.

Unix 설치·암호화 저장소·시작·재시작은 검증했으며, Unix 실제 계정 송수신·휴지통·AI 대화 시험과 사람 보안 검토는 남아 있습니다. Linux ARM 배포, macOS SSH 금고와 macOS 서명·공증은 제공하지 않습니다. 개인 비밀번호나 인증 코드를 공유하지 마세요.
