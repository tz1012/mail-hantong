한통으로 연결하세요.

외부 에이전트에 메일 도구를 연결하고, 발송·휴지통 이동은 직접 확인하세요. 운영체제에 맞는 파일을 설치하면 CLI·통신풍 TUI도 함께 이용할 수 있습니다.

beta.27: Windows의 기존 계정·키를 보존하면서 Mac Intel·Apple Silicon과 Linux x64 설치 파일을 제공합니다. Linux는 GUI 없는 서버에서 터미널로 암호화 금고를 열고 시작할 수 있습니다.

beta.27 Unix 연결 진단: Linux·Mac에서 Gmail 연결 후 받은편지함·동기화를 시작할 때 미지원 오류로 멈추던 CLI 문제를 수정했습니다. 이전 버전에 포함된 수정으로 완전한 Google HTTP 응답 뒤 TLS 종료 오류와 IMAP/SMTP 숨김 입력·보호 저장 실패를 단계별로 구분합니다. 중단된 기존 IMAP 설정은 계정 ID를 유지하며 같은 터미널에서 명시적으로 재개할 수 있습니다. 인증서 검증과 불완전 응답 거부는 유지합니다. 실제 Google·Daum 계정 연결과 메일 읽기 재시험, 사람 보안 검토는 남아 있습니다. 수정·검증 범위를 확인하세요.

Linux 다운로드

설치한 뒤에는

  1. 실행: hantong --version으로 버전을 확인하고 hantong --lang ko로 시작합니다.
  2. 계정 연결: Google 또는 일반 IMAP/SMTP 연결 안내를 따릅니다. 여러 계정은 기존 연결을 유지하며 추가합니다.
  3. 메일 이용: CLI 또는 통신풍 TUI에서 메일을 읽고 작성합니다. AI 연결은 선택 기능입니다.

Unix 압축 파일은 새 폴더에 풀고 sh install.sh를 실행합니다. Linux 서버에서는 최초 실행 시 1) headless passphrase를 선택하고, Core 재시작 시 터미널에서 금고를 잠금 해제합니다. macOS는 잠금 해제된 Keychain이 필요합니다.

업데이트는 hantong update로 진행합니다. 구버전 오류·문제 해결과 beta.27 검증 범위도 확인하세요.

외부 MCP 연결

외부 데스크톱 에이전트에서 메일 도구를 쓰려면 v3 등록을 별도로 검토합니다. 기존 v2 등록은 자동으로 확장되지 않습니다.

hantong-mcp register
hantong review --kind registration --request-id REQUEST_ID
hantong-mcp status REQUEST_ID
hantong-mcp doctor
hantong-mcp config
hantong-mcp notify on
hantong-mcp notify pending
hantong-mcp watch

Core는 약 60초 간격으로 이벤트를 확인하고 MCP 조회는 약 5초 간격으로 보류 상태를 읽습니다. 감시가 멈추면 hantong-mcp notify pending으로 보류된 이벤트를 확인하고 hantong-mcp notify ack CURSOR로 확인하세요. 메일 도착이 외부 모델을 자동으로 깨우거나 대화를 실행하지는 않습니다. 본문 조회 결과는 허용한 계정·도구 범위에 따라 외부 AI로 전달될 수 있습니다. 발송·단일 메일 휴지통 이동은 같은 터미널에서 건별로 확인해야 합니다.

파일 확인과 알려진 제한

SHA256SUMS로 다운로드한 파일을 확인하세요. 소스·빌드 정보·검증 범위는 GitHub 릴리스 원문에 있습니다.

Unix 설치·암호화 저장소·시작·재시작은 검증했으며, Unix 실제 계정 송수신·휴지통·AI 대화 시험과 사람 보안 검토는 남아 있습니다. Linux ARM 배포, macOS SSH 금고와 macOS 서명·공증은 제공하지 않습니다. 개인 비밀번호나 인증 코드를 공유하지 마세요.
