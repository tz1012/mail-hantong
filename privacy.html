Windows 메일 클라이언트 · 개발 미리보기

개인정보처리방침

이 문서는 한통의 검토된 Windows 개발 빌드에서 확인한 데이터 처리 흐름을 설명합니다. Google의 앱 검증을 통과했다거나 모든 환경에서 보안을 보장한다는 뜻은 아닙니다.

접근하는 정보와 목적

  • Google 계정의 식별자와 확인된 이메일 주소: 연결한 계정을 구분하고 올바른 계정의 토큰을 사용하는 데 필요합니다.
  • OAuth 토큰 및 앱 자격증명: 사용자가 허용한 Google API 접근과 인증 갱신에 사용합니다. Google 비밀번호를 한통에 입력하는 방식은 사용하지 않습니다.
  • 사용자가 동기화·조회한 메일의 식별자, 라벨, 제목, 발신자 등 메타데이터와 본문: PC에서 목록·검색·본문 읽기를 제공하는 데 사용합니다.
  • 작성한 수신자·제목·본문·첨부: 로컬 초안과 발송 확인을 준비하고, 사용자가 확인한 발송 요청을 Google에 전달하는 데 사용합니다.
  • 선택한 수신 첨부: 검증 요청 시 바이트를 받아 파일명·크기·내용 해시를 확인합니다. 현재 검증 캐시에는 첨부 메타데이터와 해시가 기록되며, 이 검증 경로를 일반 첨부 파일 자동 저장 기능으로 설명하지 않습니다.

저장 위치와 보호 방식

계정 정보, 메일 캐시, 초안, 감사·작업 이력은 현재 Windows 사용자의 로컬 앱 데이터 아래 한통의 암호화 데이터베이스에 보관됩니다. OAuth 토큰·앱 자격증명은 Windows DPAPI CurrentUser로 보호된 저장 경로에서 다룹니다. 발송 대기 첨부는 초안 내용과 결속된 데이터로 저장됩니다. 버전 이전 과정에서 암호화 백업이 남을 수 있습니다.

이러한 보호는 로그인된 Windows 계정이나 관리자 권한이 침해된 상황까지 막는다는 보장이 아닙니다. 다른 프로그램, 사용자가 내보낸 파일, 별도로 복사한 백업의 보호 상태는 다를 수 있습니다.

Google과의 통신 및 메일 전달

계정 연결·갱신에는 Google 인증 서비스를, 계정 확인과 메일 기능에는 Google API를 사용합니다. 요청된 메일 데이터는 Google에서 PC로 내려오며, 발송을 확인하면 수신자·본문·첨부가 Google에 제출되고 해당 수신자에게 전달됩니다. 검토한 Gmail 경로는 개발자 중계 서버를 통하지 않습니다.

Google 수정 권한은 앱에서 제공하는 기능보다 넓을 수 있습니다. 한통의 삭제 기능 차단과 Google이 부여한 권한의 범위는 서로 다릅니다.

외부 AI와 사용자가 요청하는 공유

기본 AI 세션에는 메일 에이전트가 연결되지 않습니다. 사용자가 AI 대화를 시작하면 입력한 프롬프트와 대화 맥락이 선택한 공급자(예: OpenAI 또는 Anthropic)의 공식 클라이언트를 통해 처리될 수 있습니다. 메일 에이전트를 활성화하고 계정별 권한·외부 AI 동의를 부여한 경우에는 허용된 도구가 반환한 계정·메일 정보가 AI 서비스로 전달될 수 있습니다. 발송에는 별도 네이티브 확인이 유지됩니다.

외부 AI 서비스의 보관, 학습 이용 설정, 처리 위치와 요금은 해당 서비스·계정 설정에 따라 확인해야 합니다. 이 앱이 모든 공급자의 처리 조건을 일괄 통제하거나 보관하지 않음을 보장하지 않습니다. 민감한 내용을 프롬프트에 직접 붙여넣는 것도 외부 전송입니다.

점검한 기능에는 메일 데이터를 광고용으로 판매하거나 별도 학습 데이터셋으로 수집하는 경로가 없습니다. 이는 외부 AI 공급자의 모든 처리를 검증했다는 의미는 아닙니다.

진단·감사 기록

구조화된 진단은 단계, 시각, 소요 시간과 고정 오류 코드 등을 기록합니다. Google 인증 code/state·토큰·앱 비밀값·메일 본문을 진단 필드로 넣지 않도록 구현돼 있습니다. 별도 로컬 감사 기록에는 요청자/등록/계정 식별자, 작업 종류, 결과 및 승인·발송과의 연결 정보가 남을 수 있습니다.

일반 메일 조회 결과나 사용자가 저장한 터미널 출력은 메일 내용을 포함할 수 있으므로 진단 로그와 같다고 취급하지 마세요. 문제 신고 시에도 비밀값·메일 원문을 공개 이슈나 채팅에 올리지 마세요.

보존, 연결 철회와 삭제

검토한 개발 빌드에서는 전체 Gmail 로컬 데이터의 자동 보존기간과 단일 완전 삭제 명령을 확인하지 못했습니다. 데이터·작업 이력·백업이 PC에 남을 수 있습니다. 제공된 CLI 제거 도구도 메일 데이터와 키를 보존하도록 구현돼 있습니다.

Google 접근을 중단하려면 Google 계정의 연결된 앱 관리에서 한통의 접근 권한을 제거할 수 있습니다. Google 권한 철회는 이미 PC에 저장된 캐시·초안·백업이나 상대에게 발송된 메일을 삭제하지 않습니다.

로컬 데이터 삭제가 필요하면 앱 사용을 중단하고 데이터·보호 키·프로필·별도 백업의 범위를 먼저 확인해야 합니다. 현재는 검증된 일괄 삭제 화면이 없으므로 아래 문의 경로로 절차를 확인해 주세요. 키만 지우면 남은 데이터의 복구가 불가능해질 수 있습니다. 실제 데이터나 키를 문의에 첨부할 필요는 없습니다.

이 안내 웹사이트

준비된 안내 페이지에는 로그인 폼, 분석 스크립트, 광고, 외부 폰트 또는 앱의 메일 저장소 접근 코드가 없습니다. GitHub Pages에 공개할 경우 호스팅 제공자인 GitHub가 IP 주소·접속 시각 등 서비스 이용 정보를 처리할 수 있습니다. GitHub 개인정보 안내를 참고하세요. 외부 링크를 열거나 문의를 보내면 해당 서비스의 처리 조건도 적용됩니다.

문의와 변경

운영자와 문의 주소는 이 페이지 하단에 표시돼 있으며 기존 공개 소프트웨어 라이선스에도 기재돼 있습니다. 문의로 제공한 내용은 문의 처리를 위해 해당 메일 서비스에서 처리될 수 있습니다. 앱 기능이나 데이터 흐름이 바뀌면 이 안내를 함께 검토해야 합니다.
