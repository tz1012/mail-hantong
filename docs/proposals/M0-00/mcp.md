## MCP-01 전송과 다중 호스트

- 우선순위: `P0`  
- 단계: `1`  
- 작업 카드: `M6-01,M6-07`  
- 원문 위치: [T17-R2-MCP-01](source-content.md#T17-R2-MCP-01)

### 원문 설명

기본은 호스트가 띄우는 stdio 서버이며, 이 프로세스가 로컬 IPC로 코어에 붙는다. 여러 호스트(Claude Desktop, Claude Code 등)의 동시 접속을 지원한다.

### 수용 기준 후보

> 원문 수용 기준 전체: 두 호스트가 같은 초안을 수정하면 expected_version 충돌로 처리된다. 코어 미실행 시 CORE_UNAVAILABLE을 반환한다.

검토용 수용기준 후보: AC 식별자는 원문 문장 경계에 부여했다. 설명·원문 전체·단계·조건·예외를 함께 해석한다. 복합 항목과 단계별 적용 범위는 검토가 남아 있다. AC 개수는 독립 시험 수 또는 구현 완료 수가 아니다.

- **MCP-01-AC01** 두 호스트가 같은 초안을 수정하면 expected_version 충돌로 처리된다.
- **MCP-01-AC02** 코어 미실행 시 CORE_UNAVAILABLE을 반환한다.

## MCP-03 클라이언트별 권한 프로필

- 작업 카드: `M6-02`  
- 원문 위치: [T17-R4-MCP-03](source-content.md#T17-R4-MCP-03)

### 원문 설명

MCP 클라이언트별 계정·도구·읽기 전용·한도를 설정한다. 첫 연결 등록은 GUI 또는 승인 도우미에서 승인하며, 인증된 주체·세션과 등록을 결속한다. CLI와 MCP에 동일한 권한 검사를 적용한다.

### 수용 기준 후보

> 원문 수용 기준 전체: 미등록 클라이언트는 accounts.list를 포함한 메일 도구를 호출하지 못한다. 등록 전 예외는 3.5로 한정하며 계정 정보를 노출하지 않는다. 감사에는 인증된 client_id를 기록한다.

검토용 수용기준 후보: AC 식별자는 원문 문장 경계에 부여했다. 설명·원문 전체·단계·조건·예외를 함께 해석한다. 복합 항목과 단계별 적용 범위는 검토가 남아 있다. AC 개수는 독립 시험 수 또는 구현 완료 수가 아니다.

- **MCP-03-AC01** 미등록 클라이언트는 accounts.list를 포함한 메일 도구를 호출하지 못한다.
- **MCP-03-AC02** 등록 전 예외는 3.5로 한정하며 계정 정보를 노출하지 않는다.
- **MCP-03-AC03** 감사에는 인증된 client_id를 기록한다.
