## REM-01 기기 페어링

- 우선순위: `P0`  
- 단계: `2`  
- 작업 카드: `—`  
- 원문 위치: [T21-R6-REM-01](source-content.md#T21-R6-REM-01)

### 원문 설명

새 기기는 호스트 GUI 또는 기존 기기의 QR·코드로 페어링하고 기기별 키를 발급한다.

### 수용 기준 후보

> 원문 수용 기준 전체: 페어링 코드는 1회용이며 짧은 만료 시간을 갖는다.

- **REM-01-AC01** 페어링 코드는 1회용이며 짧은 만료 시간을 갖는다.
