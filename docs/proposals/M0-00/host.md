# HOST 요건

상태: 채택 전 검토 제안

## HOST-01 헤드리스 실행

- 우선순위: `P0`  
- 단계: `2`  
- 작업 카드: `—`  
- 원문 위치: [T21-R2-HOST-01](source-content.md#T21-R2-HOST-01)

### 원문 설명

코어는 GUI 없이 실행되고 재부팅 후 자동 시작한다. 사용자가 로그인하지 않은 상태에서 비밀 저장소를 여는 방식(전용 서비스 계정 또는 부팅 후 잠금 해제)을 확정한다.

### 수용 기준 후보

> 원문 수용 기준 전체: 재부팅 후 사람이 개입하지 않거나, 개입이 필요하면 휴대폰으로 알린다.

검토용 수용기준 후보: AC 식별자는 원문 문장 경계에 부여했다. 설명·원문 전체·단계·조건·예외를 함께 해석한다. 복합 항목과 단계별 적용 범위는 검토가 남아 있다. AC 개수는 독립 시험 수 또는 구현 완료 수가 아니다.

- **HOST-01-AC01** 재부팅 후 사람이 개입하지 않거나, 개입이 필요하면 휴대폰으로 알린다.
