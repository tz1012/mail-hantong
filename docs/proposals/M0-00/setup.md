## SETUP-01 단계별 설정 마법사

- 우선순위: `P0`  
- 단계: `1`  
- 작업 카드: `M9-01`  
- 원문 위치: [T27-R2-SETUP-01](source-content.md#T27-R2-SETUP-01)

### 원문 설명

GUI와 CLI(hantong setup)가 같은 단계를 제공한다: 설치 구성 확인 → OAuth 클라이언트 준비 → 계정 연결 → 승인 수단 등록 → 알림 → 백업 위치 → 에이전트 연결 → 검증. 단계마다 건너뛰기·나중에 하기가 있고, 진행 상태는 INST-09 연결 세션과 같은 방식으로 저장해 이어간다.

### 수용 기준 후보

> 원문 수용 기준 전체: 마법사를 중간에 닫았다가 다시 열면 남은 단계부터 시작한다. hantong setup --step &lt;단계&gt;로 어느 단계든 다시 실행할 수 있다.

검토용 수용기준 후보: AC 식별자는 원문 문장 경계에 부여했다. 설명·원문 전체·단계·조건·예외를 함께 해석한다. 복합 항목과 단계별 적용 범위는 검토가 남아 있다. AC 개수는 독립 시험 수 또는 구현 완료 수가 아니다.

- **SETUP-01-AC01** 마법사를 중간에 닫았다가 다시 열면 남은 단계부터 시작한다.
- **SETUP-01-AC02** hantong setup --step &lt;단계&gt;로 어느 단계든 다시 실행할 수 있다.

## SETUP-02 BYO OAuth 클라이언트

- 우선순위: `P0`  
- 단계: `1`  
- 작업 카드: `M9-02`  
- 원문 위치: [T27-R3-SETUP-02](source-content.md#T27-R3-SETUP-02)

### 원문 설명

1·2단계 기본 경로로, 사용자가 자신의 Google Cloud 프로젝트와 Microsoft 앱 등록을 만들고 클라이언트 ID를 입력하도록 화면별로 안내한다. Google은 Gmail API 사용 설정, 동의 화면, 데스크톱 클라이언트 생성까지, Microsoft는 계정 유형 선택과 공개 클라이언트 리디렉트 설정까지 다룬다.

### 수용 기준 후보

> 원문 수용 기준 전체: 입력한 값으로 시험 로그인을 해 보고 실패 원인을 단계별로 알려 준다. 게시 상태(테스트·운영)에 따른 토큰 만료 조건 차이를 안내하고, 만료가 다가오면 재인증을 알린다. 세부 조건은 착수 시 재확인한다.

- **SETUP-02-AC01** 입력한 값으로 시험 로그인을 해 보고 실패 원인을 단계별로 알려 준다.
- **SETUP-02-AC02** 게시 상태(테스트·운영)에 따른 토큰 만료 조건 차이를 안내하고, 만료가 다가오면 재인증을 알린다.
