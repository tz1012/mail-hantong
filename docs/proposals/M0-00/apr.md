# APR 요건

상태: 채택 전 검토 제안

## APR-01 승인 요청 흐름

- 우선순위: `P0`  
- 단계: `1`  
- 작업 카드: `M5-02,M5-12`  
- 원문 위치: [T14-R2-APR-01](source-content.md#T14-R2-APR-01)

### 원문 설명

승인이 필요한 호출은 approval_request를 만들고 APPROVAL_REQUIRED를 반환한다. 요청에는 작업 해시, 계정, 대상, 수신자, 첨부 요약, 요청한 클라이언트, 만료 시각이 담긴다.

### 수용 기준 후보

> 원문 수용 기준 전체: 요청 후 내용이 바뀌면 기존 요청은 무효가 된다. 요청 생성과 승인 발급은 별도 권한이며 CLI·MCP는 요청·상태 조회만 한다. 요청 생성 응답을 승인으로 사용할 수 없다.

검토용 수용기준 후보: AC 식별자는 원문 문장 경계에 부여했다. 설명·원문 전체·단계·조건·예외를 함께 해석한다. 복합 항목과 단계별 적용 범위는 검토가 남아 있다. AC 개수는 독립 시험 수 또는 구현 완료 수가 아니다.

- **APR-01-AC01** 요청 후 내용이 바뀌면 기존 요청은 무효가 된다.
- **APR-01-AC02** 요청 생성과 승인 발급은 별도 권한이며 CLI·MCP는 요청·상태 조회만 한다.
- **APR-01-AC03** 요청 생성 응답을 승인으로 사용할 수 없다.

## APR-02 신뢰 채널

- 우선순위: `P0`  
- 단계: `1`  
- 작업 카드: `M5-03,M5-08,M8-10`  
- 원문 위치: [T14-R3-APR-02](source-content.md#T14-R3-APR-02)

### 원문 설명

1단계는 등록된 GUI 승인 화면 또는 승인 도우미, 2단계는 페어링 휴대폰도 사용한다. 일반·고위험 승인 모두 요청에 결속된 사용자 확인 증거를 검증한다. 휴대폰은 생체 확인 후 기기 키로 서명한다.

### 수용 기준 후보

> 원문 수용 기준 전체: 무등록 채널·기기, 사용자 확인 증거 없음, 세션 불일치, 휴대폰 서명 없음, 만료·재사용된 증거는 거부한다. 일반 GUI의 확인 수단은 승인된 ADR로 확정한다.

검토용 수용기준 후보: AC 식별자는 원문 문장 경계에 부여했다. 설명·원문 전체·단계·조건·예외를 함께 해석한다. 복합 항목과 단계별 적용 범위는 검토가 남아 있다. AC 개수는 독립 시험 수 또는 구현 완료 수가 아니다.

적용 범위 검토: 휴대폰 서명 조건은 2단계 휴대폰 경로다. 각 거부 사례의 채널 적용성을 검토한다.

- **APR-02-AC01** 무등록 채널·기기, 사용자 확인 증거 없음, 세션 불일치, 휴대폰 서명 없음, 만료·재사용된 증거는 거부한다.
- **APR-02-AC02** 일반 GUI의 확인 수단은 승인된 ADR로 확정한다.

- **APR-06-AC01** 만료·거절된 요청으로 실행되지 않는다.

## APR-07 승인 요청 남발 방지

- 단계: `1`  
- 작업 카드: `M5-10`  
- 원문 위치: [T14-R8-APR-07](source-content.md#T14-R8-APR-07)

### 원문 설명

클라이언트별 빈도 상한을 두고, 같은 인증 클라이언트·계정·작업 해시·대상 버전의 대기 요청만 묶는다. 반복 거절 시 해당 클라이언트의 요청을 일시 정지하고 알린다. 화면은 대기 수와 인증된 요청자를 표시한다.

### 수용 기준 후보

> 원문 수용 기준 전체: 상한 초과 시 APPROVAL_RATE_LIMITED를 반환한다. 서로 다른 클라이언트·계정의 요청은 합치지 않는다. 연속 승인 사이에 내용 확인 시간을 두며 요청 묶기가 승인 재사용이 되지 않는다.

검토용 수용기준 후보: AC 식별자는 원문 문장 경계에 부여했다. 설명·원문 전체·단계·조건·예외를 함께 해석한다. 복합 항목과 단계별 적용 범위는 검토가 남아 있다. AC 개수는 독립 시험 수 또는 구현 완료 수가 아니다.

- **APR-07-AC01** 상한 초과 시 APPROVAL_RATE_LIMITED를 반환한다.
- **APR-07-AC02** 서로 다른 클라이언트·계정의 요청은 합치지 않는다.
- **APR-07-AC03** 연속 승인 사이에 내용 확인 시간을 두며 요청 묶기가 승인 재사용이 되지 않는다.
