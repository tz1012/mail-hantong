## EXT-01 제공자와 연결 방식 선택

- 우선순위: `P0`  
- 단계: `1`  
- 작업 카드: `M2-01`  
- 원문 위치: [T10-R2-EXT-01](source-content.md#T10-R2-EXT-01)

### 원문 설명

Google, Microsoft, 네이버, Daum, 기타 IMAP·SMTP 연결 유형을 제공한다. 자동 발견은 제안이며 서버·포트·TLS·인증·로그인 이름을 확인·수정할 수 있다.

### 수용 기준 후보

> 원문 수용 기준 전체: IMAP 수신 성공과 SMTP 발송 실패를 별도 상태로 표시한다. 회사 도메인을 Gmail 또는 Microsoft라고 임의 확정하지 않는다.

검토용 수용기준 후보: AC 식별자는 원문 문장 경계에 부여했다. 설명·원문 전체·단계·조건·예외를 함께 해석한다. 복합 항목과 단계별 적용 범위는 검토가 남아 있다. AC 개수는 독립 시험 수 또는 구현 완료 수가 아니다.

- **EXT-01-AC01** IMAP 수신 성공과 SMTP 발송 실패를 별도 상태로 표시한다.
- **EXT-01-AC02** 회사 도메인을 Gmail 또는 Microsoft라고 임의 확정하지 않는다.

- **EXT-04-AC01** 폴더 재생성·메일 이동·UID 변경으로 다른 메일에 읽음·삭제 작업을 잘못 적용하지 않는다.

- 작업 카드: `M2-02`  
- 원문 위치: [T10-R6-EXT-05](source-content.md#T10-R6-EXT-05)

### 원문 설명

IMAP CAPABILITY와 SMTP 확장을 확인한다. IDLE, MOVE, UIDPLUS, CONDSTORE·QRESYNC 등이 없을 때 안전한 대체 경로 또는 미지원 상태를 제공한다.

### 수용 기준 후보

> 원문 수용 기준 전체: IDLE 연결 종료 시 재연결·폴링으로 복구하며 정기 전체 대조를 수행한다. MOVE 미지원 서버에서 COPY·삭제 대체가 다른 삭제 대기 메일까지 EXPUNGE하지 않도록 한다.

검토용 수용기준 후보: AC 식별자는 원문 문장 경계에 부여했다. 설명·원문 전체·단계·조건·예외를 함께 해석한다. 복합 항목과 단계별 적용 범위는 검토가 남아 있다. AC 개수는 독립 시험 수 또는 구현 완료 수가 아니다.

- **EXT-05-AC01** IDLE 연결 종료 시 재연결·폴링으로 복구하며 정기 전체 대조를 수행한다.
- **EXT-05-AC02** MOVE 미지원 서버에서 COPY·삭제 대체가 다른 삭제 대기 메일까지 EXPUNGE하지 않도록 한다.
