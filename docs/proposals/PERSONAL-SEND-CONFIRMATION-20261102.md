# 개인 CLI 발송 확인 요건 변경 제안

2026-11-02 사용자는 직접 작성한 메일을 간단히 보내도록 재설계를 지시했다. APR-02~04, 특히 APR-04-AC01과 INST-04의 OS 본인 확인 조건에 개인 Google CLI의 좁은 예외를 제안한다. 기준 requirements 원문은 변경하지 않는다.

예외는 ADR-028의 Core/Store 등록 판정과 네이티브 전체 내용 표시·명시적 보내기 버튼을 모두 만족할 때만 적용한다. CLI yes 입력, MCP 확인, 메일 본문은 발송 증거가 아니다. 다른 등록·설정·대량 변경은 기존 보호를 유지한다. 불변 내용 결속, 단일 소비, 만료, audit/outbox, SEND_UNKNOWN 무재전송은 동일하다.

수용 검증: 정확한 개인 출처만 새 경로 허용, 범위·계정·epoch·endpoint 변경 시 claim 거부, 취소·만료·표시 전 클릭·snapshot 치환 시 전송 없음, 개인 버튼에서 OS verifier 호출 없음, 보호 경로의 OS Verified 조건 유지. 같은 사용자 AI의 UI 자동화 방어 약화는 잔여 위험이며 사람 보안 검토가 필요하다.
