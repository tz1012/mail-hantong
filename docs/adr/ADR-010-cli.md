# ADR-010 CLI 초기 구문과 리소스

상태: 2026-10-29 연속 개발 위임에 따른 초기 구현 결정.

초기 help/version/거부 경계는 Rust 표준 라이브러리로 구현한다. 명령이 소수이고 외부 라이브러리가 없어도 구문과 종료 코드를 검증할 수 있다. 전체 명령 트리·완성 기능이 연결될 때 clap 등 후보를 별도 비교한다. 지금의 선택을 전체 CLI 프레임워크 결정이 끝난 것으로 확대하지 않는다.

외부 parser를 지금 도입하는 선택은 도움말/하위 명령 기능이 풍부하지만 의존성·라이선스 범위를 늘린다. 수작업 parser는 입력 검증을 직접 시험해야 하므로 초기 명령 밖의 입력은 거부하고 확장 때 복잡도를 재검토한다. 명령과 오류 코드는 [초기 계약](../contracts/cli-bootstrap.md), [종료 코드](../contracts/cli-exit-codes.md)를 따른다.

영어·한국어 문구는 별도 UTF-8 리소스에 두고 빌드 시 키의 동등성을 검사한다. GUI 언어와 독립적이며 원문 데이터와 기계 식별자를 번역하지 않는다.
