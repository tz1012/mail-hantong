# ADR-016 프로젝트 라이선스

상태: **확정 — 2026-10-29, 사용자 Andrew Cho의 명시적 승인**

관련 작업: M0-01 저장소 골격, GitHub 공개 준비, M9-15 의존성·라이선스 고지.

## 결정

프로젝트 라이선스로 **mail-hantong Source-Available License — Version 1.0**을 채택한다. 정식 영문 문안의 단일 기준은 루트 [LICENSE](../../LICENSE)다. [한국어 안내](../latest/LICENSING.md)는 해당 문안의 요약이다.

사용자는 개인·회사 내부 업무용 사용, 수정본 비공개, 원본·수정본 무료 재배포를 허용하고 프로그램 재판매·유료 서비스 제공 등 수익화를 금지하는 정책을 정했다. 이어 저작권 고지 유지·수정본 표시·보증 없음 조항을 담은 [검토 초안](../latest/LICENSING-DRAFT.md)을 정식 라이선스로 채택하는 질문에 “네”라고 답했다.

초안의 영문 여섯 조항은 그대로 옮겼다. 정식 채택에 따라 제목의 `Draft 0.1`만 `Version 1.0`으로 바꿨다. 이 승인으로 라이선스 문안 검토를 완료하며, 추가 사용 조건을 임의로 붙이지 않는다.

## 반영과 남은 작업

- 루트 LICENSE, README와 최신 안내를 채택된 문안에 연결한다. 초안과 이전 제안은 경과로 보존한다.
- M0-01의 ADR-016 결정 선행 조건은 충족했다. ADR-001의 Rust 결정과 [M0-00 기준 요건](../requirements/README.md)도 각각 별도 사용자 승인을 기록했다. 카드 완료 여부는 해당 검증 근거와 상태장부를 따른다.
- 제3자 라이브러리·복사한 코드·이미지 등의 배포 조건, 고지와 SBOM은 채택·배포 시 별도로 확인한다. 프로젝트 라이선스 채택을 제3자 조건 검토 완료로 기록하지 않는다.
- GitHub 저장소 게시, 릴리스 업로드, 설치 패키지 배포는 아직 수행하지 않았다. 이번 승인은 라이선스 문안 채택에 관한 것이다.

## 재검토 조건

새 사용 조건이 필요하거나 제3자 구성 요소와의 호환성 문제가 발견되면 변경 이유·영향을 정리해 별도로 결정한다. 이미 배포한 버전에 부여한 권리가 새 문안으로 자동 소멸한다고 가정하지 않는다.
