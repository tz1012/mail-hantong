## 사용자에게 안내할 요약

- 개인 사용과 회사 내부 업무용 사용을 허용한다.
- 원본·수정본의 무료 재배포를 허용한다. 소스 또는 실행 파일로 배포할 수 있다.
- 수정본의 소스를 공개할 의무를 두지 않는다. 무료 실행 파일 재배포에도 이 원칙을 적용한다.
- 원본·수정본의 판매와 유료 서비스 제공 등 프로그램 자체를 통한 수익화는 금지한다.
- 재배포 시 저작권·라이선스 고지를 유지하고 수정본임을 표시하는 조건을 제안한다.
- 제3자 구성 요소에는 해당 구성 요소의 라이선스가 별도로 적용된다.

저작권자는 **Andrew Cho**, 웹사이트는 **https://tzt.kr**, 연락처는 **andrew@tzt.kr**이다. 웹사이트와 이메일은 연락 정보이며 별도 저작권자를 뜻하지 않는다.

판매 제한이 있는 소스 공개 라이선스이므로 OSI 오픈소스로 표시하지 않는다. [OSI 정의 §1](https://opensource.org/osd)
