# mail-hantong 라이선스 안내

상태: **2026-10-29 사용자 승인으로 Version 1.0 정식 채택**.

정식 문안은 루트 [LICENSE](../../LICENSE), 결정 근거는 [ADR-016](../adr/ADR-016-license.md)이다. 이 문서는 한국어 요약이며 영문 라이선스에 없는 추가 권리나 제한을 만들지 않는다.

- **허용:** 개인 사용, 회사 내부 업무용 사용, 수정본 비공개, 원본·수정본의 무료 재배포.
- **소스 공개 의무 없음:** 수정한 실행 파일을 무료로 재배포해도 이 프로젝트 라이선스는 수정 소스 공개를 강제하지 않는다.
- **금지:** 프로그램이나 수정본의 판매·대여, 접근·사용 대가 청구, 유료 호스팅·관리 서비스 제공. 일반적인 사업에서 내부 메일 도구로 사용하는 것은 허용한다.
- **재배포 조건:** 라이선스와 저작권 고지를 유지하고, 수정본은 수정되었음을 표시하며 Andrew Cho의 공식 배포본으로 표시하지 않는다.
- **제3자 구성 요소:** 해당 구성 요소의 원래 라이선스·고지·소스 제공 등 적용되는 조건을 별도로 준수한다.
- **보증과 책임:** 적용 법률이 허용하는 범위에서 보증 없이 제공하며 책임을 제한한다. 법적으로 배제할 수 없는 책임은 제외하지 않는다.

저작권자는 **Andrew Cho**, 웹사이트는 **https://tzt.kr**, 연락처는 **andrew@tzt.kr**이다.
