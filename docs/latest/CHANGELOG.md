# v2.3 변경 내역

2026년 10월 29일 사용자가 제품 이름, CLI 이름, GUI 초기 영·한 및 세 테마, CLI 영어 지원을 지정했다. v2.2의 기본 기능과 안전 원칙을 유지하며 다음을 반영했다.

- 제품·솔루션 이름을 `mail-hantong`, CLI 명령을 `hantong`으로 명시하고 명령 예제를 갱신했다. MCP `mail.*` 도구 이름과 기계 식별자는 유지한다.
- OPS-07 GUI 초기 영한 지원, OPS-08 라이트·다크·시스템 테마, CLI-16 CLI 영어 기본 지원을 P0·1단계로 추가했다. 기존 ID 167개와 우선순위·단계는 보존한다.
- CLI-01·02·07, OPS-02·03을 보강하고 다른 요건의 CLI 명령 예제도 수정했다. 전후 비교 기록은 수정된 기존 요건 17개와 새 요건 3개를 포함한다.
- GUI와 먼저 만드는 승인 도우미의 최초 화면부터 두 언어·세 테마를 요구했다. CLI 골격도 최초 구현부터 영어 리소스를 사용한다.
- M1-12, M8-18, M8-19, M9-20 카드 4개와 수용시험 31~33을 추가했다. M8·Gate 1의 선행 조건과 상태장부를 동기화했다.
- `DESIGN.md`에 세 참고 저장소의 관찰과 적용 방향, 정보 구조, 접근성, 리소스·테마 정책, 화면별 완료 기준을 정리했다. 이 버전에는 `DESIGN.md`를 보관한다.
- 설정 계약에 `ui.language`, `ui.theme`, `cli.language`, `--lang`의 논리 요구를 추가했다. 실제 스키마·제품 구현·기술 채택을 완료한 것으로 표시하지 않는다.

총 요건은 170개, 1단계 P0는 144개, 활성 카드는 151개다. 기존 CLI-15 클라이언트 프로필과 M1-11 자동 시작 카드를 유지했으며 새 ID와 충돌하지 않는다.

## 2026-10-29 개발 시작에 따른 보완

- `PROGRESS.md`를 단일 진행 기록으로 추가했다. 작업 결과·검증·남은 결정은 이 문서에 누적한다.
- `DISTRIBUTION.md`에 사용자가 지정한 GitHub 공개와 명령어 설치·개발 환경 목표를 기록했다. 일반 사용자 설치와 기여자 개발, 공개 OAuth 운영을 구분했다.
- 루트 README와 최신 모음의 진입점·개발 지침·기능 범위에서 두 문서를 연결했다.
- M0-00의 요건 분할 도구·검토 산출물을 생성하고 문서 도구 시험 21개를 통과했다. 카드 상태는 사람 검토 필요이며, 세부 결과는 `PROGRESS.md` 및 `card-status.csv`에서 확인한다.
- 기존 Word v2.3과 요건 ID·우선순위·단계 및 카드 범위는 유지했다. 이 보완은 제품 기술 채택이나 공개 릴리스 완료를 뜻하지 않는다.

## 2026-10-29 사용자 승인에 따른 성능 목표 변경

- 사용자 확인으로 웜 캐시 상태에서 기본 메일 목록 사용까지의 목표를 3초에서 1초 이내로 강화했다. OPS-01과 원문 §13.1의 앱 시작 항목에 해당한다.
- 현재 기준은 `FEATURES.md`의 성능 보완에 기록하고 README·런타임 비교안·진행 기록을 연결했다. 보관 Word와 원문 추출본의 내용은 보존했다.
- 실제 성능 검증과 언어·GUI 채택은 아직 진행 전이다.

## 2026-10-29 Mac 후속 지원 승인

- 사용자 승인에 따라 Windows 우선 출시 후 macOS를 정식 후속 목표에 포함했다.
- Mac은 로컬 코어·CLI·최소 승인 도우미를 먼저 제공하고 전체 GUI는 후속 제공한다. CLI 영어 기본과 한국어 선택, 기존 승인·비밀 입력 보호를 유지한다.
- FEATURES.md·공개 계획·런타임 비교안·진행 기록과 진입점을 갱신했다. 구체적인 카드·출시 일정·지원 OS/CPU는 후속 계획에서 정하며, 보관 Word와 원문 추출본은 수정하지 않았다.

- 정식 오픈소스 대신 비상업적 소스 공개 방식으로 안내한다. 회사 내부 업무용 사용의 범위와 실제 라이선스 문구는 아직 확인 중이다.

## 2026-10-29 코어·CLI Rust 채택

- 사용자가 시작 속도와 메모리 사용을 함께 고려해 Rust를 선택했다. 정식 ADR-001에 확정 상태와 후속 조건을 기록했다.
- 최신 안내와 활성 작업 규칙을 Rust 기준으로 갱신했다. C# 전용 라이브러리 제안은 별도 재검토로 표시했으며 GUI·개별 crate·toolchain 버전은 자동 채택하지 않았다.
- 1초 시작 목표와 실측 원시 결과를 유지한다. M0-00·M0-01 카드나 제품 성능 수용 기준을 완료 처리하지 않았다.
