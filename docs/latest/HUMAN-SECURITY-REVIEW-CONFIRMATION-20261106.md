## 전달된 실제 사용자 확인

현재 사용자 메시지는 검토 대상 `6322b9a`와 `HUMAN-SECURITY-REVIEW-SCOPE-20261105.md`, 잔여 TOCTOU·Mac Keychain 호환성 공백을 안내받은 사용자가 직접 다음과 같이 확인했다고 명시한다.

> 검토 완료했어

전달 메시지의 배포 승인 관련 원문:

> 사용자는 검토 후 공식 배포·송파 업데이트·연결 시험도 승인했습니다.

위 확인은 사용자에 의해 전달된 실제 확인 원문으로 기록한다. 에이전트가 이전 확인 장면을 직접 관찰했다거나, 전달자가 대신 검토했다거나, 세부 검토 결과가 제출됐다고 기록하지 않는다. 실명·역할·원래 UTC·읽은 개별 파일·항목별 발견 사항은 제공되지 않았으므로 채우지 않는다.

## 완료 확인과 남은 배포 조건의 구분

사용자의 **대상 범위에 대한 검토 완료 확인**과 **검토 후 배포 승인**은 접수됐다. 더 이상 사람 확인 자체가 전혀 없다고 표시하지 않는다. 별도 자격증·독립 심사자·두 명의 검토자·새로운 항목별 서식 제출을 추가 요구하지 않는다.

다만 기존 범위 문서의 ‘반드시 판단할 잔여 위험’에는 다음 두 조건이 명시돼 있다. 제출된 완료 확인에 구체적인 판단·조치가 포함됐다고 추정하지 않는다.

1. **같은 UID의 검증→경로 실행 TOCTOU**: ‘허용 가능한지, 핸들 기반 실행 등 추가 설계가 배포 전 필요한지 명시해야 한다.’ 위험은 코드에 남아 있다. 알려진 위험을 현 위협 모델에서 배포 가능으로 판단한 것인지, 추가 수정이 선행돼야 하는지에 대한 명시적 결론은 전달되지 않았다.
2. **Mac 버전 간 Keychain 호환성**: ‘배포 전 추가 시험 또는 명시적인 판단·조치가 필요하다.’ 새 설치·같은 버전 재시작은 통과했지만 이전 Core 항목의 새 Core 접근 시험은 없다. 이 공백을 둔 배포의 허용 범위·조치 또는 추가 시험 결과는 전달되지 않았다.

일반적인 ‘검토 완료’나 배포 승인만으로 위 두 결론을 만들어 넣지 않는다. 배포 보류 사유는 검토 완료 확인의 부재가 아니라 **기존에 명시한 두 잔여 조건의 판단·조치 미기록**이다. 이는 AGENTS §6의 사람 검토 경계를 적용한 기존 검토 범위 문서의 구체적 조건이며, AGENTS가 이 세부 서식을 직접 요구한다고 주장하지 않는다.

공식 beta.30 tag/release·설치 채널 갱신과 송파 업데이트는 보류한다. 송파 실제 계정 연결 시험도 실행하지 않았다. 기존 계정·금고·메일·인증정보·권한 및 암호화 임시 파일을 변경하거나 초기화하지 않았고 자동 권한을 부여하지 않았다. 송파의 이전 승인 차단을 우회하지 않는다. 조건 충족 후에는 이미 주어진 배포·업데이트·연결 시험 승인을 다시 요청하지 않는다.
