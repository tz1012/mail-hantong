## 승인된 성능 목표 보완

2026-10-29 사용자가 앱 시작 목표를 **3초에서 1초 이내**로 강화하는 데 동의했다. 이 변경은 OPS-01과 Word 원문 §13.1의 ‘앱 시작’ 항목에 적용한다. Word와 원문 추출본은 보관 자료로 유지하며, 해당 항목의 현재 기준은 아래 Markdown 보완 내용이다.

- **목표:** 메일 캐시가 준비된 웜 캐시 상태에서, 앱 실행 요청부터 기본 메일 목록을 사용할 수 있을 때까지 **1초 이내**.
- **완료 시점:** 스플래시나 빈 창 표시가 아니라 메일 목록을 표시하고 사용자 입력에 반응하는 시점.
- **기준 환경:** 기존 원문의 Windows 11 x64, 4코어급 CPU, RAM 16GB, SSD, 계정 5개, 메타데이터 10만 건을 유지한다.
- **측정 구분:** 최초 설치·전체 동기화·콜드 스타트와 구분하고, 코어 실행 여부·캐시 상태·측정 시작과 끝을 결과에 기록한다. 원격 동기화 완료를 기다리는 시간과 로컬 화면 표시 시간도 구분한다.
- **현재 상태:** 사용자가 승인한 목표이며 실제 달성값은 아니다. 언어·GUI 선택과 프로토타입 측정에 적용한다. 다른 목록·본문·검색 목표는 이번 답변으로 변경하지 않았다.

## 승인된 Mac 후속 지원 방향

2026-10-29 사용자가 **Windows를 먼저 출시하고 macOS 버전을 정식 후속 목표로 포함**하는 데 동의했다. 이어 Mac에서 CLI를 우선 사용할 수 있는지 확인했으므로, Mac 지원은 **로컬 코어 + `hantong` CLI + 최소 승인 도우미를 먼저 제공하고 전체 GUI를 후속 제공**하는 순서로 구체화한다. 구체적인 출시 단계 번호·일정·지원 OS/CPU 목록은 후속 계획에서 정한다.

- 코어와 CLI는 전체 메일 GUI의 설치·실행에 의존하지 않는다. Mac에서 동기화·조회·검색·초안·일반 설정 등을 CLI로 사용할 수 있게 한다.
- 계정 연결은 기존 정책대로 시스템 브라우저 또는 보호된 설정 흐름을 사용한다. 클라이언트 등록 승인·비밀 입력·보안 설정·발송 승인은 Mac용 승인 도우미 같은 신뢰 경로에서 처리한다. 터미널 확인 입력을 승인 발급으로 사용하지 않는다.
- Mac용 비밀 저장소·로컬 IPC·사용자 확인·알림·자동 실행·설치/업데이트를 구현하고 검증해야 CLI 지원 완료로 본다. Windows 실행 파일을 그대로 사용하거나 원격 Windows 코어를 당연한 선행 조건으로 두지 않는다.
- Mac CLI도 `hantong` 명령과 영어 기본·한국어 선택, 안정적인 JSON·오류 코드·종료 코드 정책을 유지한다. 나중에 전체 GUI를 추가해도 같은 코어·계정·데이터를 사용한다.
- 초기 구조와 GUI 후보 비교에 Mac 이식성을 포함한다. 코어·CLI는 [ADR-001](../adr/ADR-001-core-runtime.md)에 따라 Rust로 확정했고 GUI 프레임워크는 미확정이다. 아직 실행 가능한 제품이나 Mac 설치 패키지는 없다.

## 기본 메일 기능


아래 9개 기본 기능은 모두 P0다. 예약 발송과 기본 규칙 자동화도 Gate 1 전에 구현·검증한다.

| 기능 | 요건 | 포함하는 기본 동작 | 구분할 사항 |
| --- | --- | --- | --- |
| 예약메일함 | MAIL-13, AI-09 | 예약 목록, 계정·시각·시간대·승인·실행 상태, 수정·취소, 실패 확인 | 시각·내용 변경은 재승인. PC가 꺼져 있으면 정시 발송 보장 없음. SEND_UNKNOWN 자동 재발송 금지 |
| 폴더 | MAIL-17, EXT-06 | 계정별 트리, 생성·이름 변경, 지원되는 계층 이동, 안전한 삭제 | 시스템 폴더 보호. 내용·하위 폴더 손실 또는 새 메일 유입 경합을 막지 못하는 삭제는 거부 |

| 즐겨찾기 | MAIL-19 | 메일 별표와 모아보기, 폴더·태그 메뉴 고정·정렬 | 메일 즐겨찾기와 탐색 메뉴 고정은 별도. 해제 시 메일·폴더 유지 |
| 스팸함 | MAIL-20 | 계정별 목록·검색, 스팸 지정·정상 복원 | 단순 이동과 제공자 신고 효과 표시. 원래 위치 또는 같은 계정의 선택 위치로 복원 |
| 광고필터 | MAIL-21 | 광고/프로모션 보기, 로컬 규칙, 분류 이유·버전·예외, 오탐 해제 | 기본은 원본 위치 유지. 광고와 스팸 구분. 자동 삭제·URL 호출·구독 해지 없음 |

| 주소록 | MAIL-22 | 연락처·복수 주소·메모·그룹 CRUD, 검색·자동완성 | 계정 전용/사용자 공용 범위, 관측 주소와 저장 연락처 구분, 그룹 주소를 확정해 발송 검토 |

모든 경로는 같은 코어의 계정 범위·권한·버전·승인 검사를 사용한다. 제공자별 지원 차이는 capability로 표시하고, 없는 서버 기능을 지원하는 것처럼 표시하지 않는다.

확장은 별도 요건으로 다룬다. 예를 들어 Google·Microsoft 주소록 동기화, 주소록 파일 대량 가져오기·내보내기, 외부 AI 광고 분류, 임의 스크립트·웹훅 자동화는 위 기본 기능에 포함하지 않는다. 저장된 연락처가 있다는 이유만으로 발신자를 신뢰하거나 안전 검사를 생략하지 않는다.
