# 요건 추적표

이 보고서는 실행 증거가 있는 경우에만 `passed` 또는 `failed`를 기록합니다. 태그나 문서 연결만으로 통과를 표시하지 않습니다.

소스 해시: `c164b5247171a129c755d81541c343fc565e391cd1c1cd6845e77e2287ed3431`

| 상태 | 개수 |
| --- | ---: |
| `failed` | 0 |
| `not_applicable` | 0 |
| `not_run` | 0 |
| `passed` | 0 |
| `review_required` | 0 |
| `unimplemented` | 341 |

상세 행은 [traceability.csv](traceability.csv)에서 확인합니다. `not_applicable`는 권위 있는 사람 검토 증거가 연결되기 전까지 예약 상태이며, 실행 증거 파일은 저장소 내부의 상대 경로만 허용합니다.
