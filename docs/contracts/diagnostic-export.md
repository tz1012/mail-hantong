# 안전한 진단 묶음 계약 v1

M1-10의 진단 묶음은 사용자가 포함 항목을 선택한 뒤 미리보기와 내보내기에 같은 불변 JSON을 사용한다. 선택 가능한 항목은 `sync`, `recent_work`, `errors`로 고정되어 있으며 빈 선택과 중복 선택은 거부한다.

현재 동기화 원천과 최근 작업 원천이 연결되지 않았으므로 두 항목은 선택되어도 `"unavailable"`로 표시한다. 구현이 값을 추정하거나 코어 준비 상태를 동기화 완료로 표현하지 않는다. 오류 항목은 수치형 오류 수와 안정 오류 코드만 포함한다.

묶음에는 메일 원문·제목·주소·계정 식별자·토큰·파일 경로·자유 텍스트·예외 문자열이 들어갈 수 없다. `schema_version`과 UTC epoch milliseconds는 고정 형식이며 시간은 음수가 될 수 없다. 미리보기와 내보내기는 동일한 직렬화 결과를 비교해 확인할 수 있다.

이 계약은 파일 쓰기, CLI 명령, 동기화 상태 수집, 사용자 확인 화면을 정의하지 않는다. 실제 상태 원천과 사용자 표시·확인 흐름이 연결되기 전에는 M1-10 전체 수용 기준을 완료로 표시하지 않는다.
