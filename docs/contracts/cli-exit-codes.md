# CLI 종료 코드 v1

[errors.md](errors.md)의 코드와 번호를 그대로 사용한다. 성공은 0이며 표의 서로 다른 오류 코드는 서로 다른 종료 값을 가진다. 번호를 재배정·재사용하지 않는다. 영어·한국어, JSON·사람용 출력, TTY·비대화형 실행에서 같은 값을 반환한다.

`SEND_UNKNOWN=17`은 일반 오류 70이나 `APPROVAL_REQUIRED=18`과 합치지 않는다. 명령 파싱 실패는 `INVALID_INPUT=2`다. OS가 프로세스를 강제 종료한 경우에는 운영체제의 종료 상태를 위장하지 않는다.

검증 대상: CLI-03, CLI-04, CLI-16. 이 계약 작성은 해당 기능 전체의 수용 기준 통과를 뜻하지 않는다.
