# v2.1 변경 내역

기준: 루트의 v2.0 Word·PDF, `AGENTS.md`, `DEVELOPMENT_GUIDE_2.md`, `stage1-tasks_1.md`. 개정본은 별도 폴더에 작성했다. 기존 161개 요건의 ID·P0/P1·단계는 유지했으며, 아래 변경은 수용 조건을 명확히 하거나 충돌을 해소한다.

| 문제 | 개정 내용 | 반영 위치 |
| --- | --- | --- |

| 일반 GUI 승인에 화면 조작 우회 가능 | 모든 승인에 요청 결속된 사용자 확인 증거, 발급·실행 직전 재검증 | APR-01~04·06~07, KEY-07, 요건서 7.3, M5·M8-10 |
| 코어 설치에서 보안 설정 경로 없음 | 승인 도우미에 보안 설정·등록 확인·보호 입력 화면 명시 | INST-02·04, 요건서 11.5, M5-04·M9-16 |

APR-05의 데스크톱 알림은 M7-06, KEY-07의 Windows 승인 입력은 M5-08·M8-10, EXT-09의 호환성 검증은 M9-05에 연결했다. M9-12는 M0~M8의 P0 종료 검토와 M9 필수 카드가 완료되어야 시작한다. 카드 135개의 번호를 유지했다.

Word에서는 원래의 표·그림·문서 구조를 유지하고 제목 스타일, 요구사항 표의 열 너비, 표 머리글 반복, 행의 페이지 분할을 정리했다. 새 설명 절은 3.5, 7.3, 12.1.1, 15.2.1, 17.4에 넣었다.

이 변경은 기술 검증이나 사람 승인이 완료되었다는 선언이 아니다. 요건서의 일반 승인 강화와 미등록 조회 예외 제거, 서버 업로드 지원 기준은 REVIEW의 명시적 검토 대상이다.
