## Word 페이지 검수

최종 DOCX를 Microsoft Word에서 읽기 전용으로 열어 다시 페이지를 계산한 뒤 검수용 PDF로 내보냈다. 묶음 런타임의 Poppler와 문서 렌더러를 사용해 87개의 PNG를 생성했다. PDF·PNG는 검수용이며 납품 문서에 포함하지 않는다.

전체 87쪽을 이미지로 확인했다. 마지막 문구 수정은 APR-02의 서명 요구를 휴대폰으로 한정한 것이며, 수정 후 이미지 비교에서 35쪽만 달라졌다. 나머지 86쪽은 이미 검수한 이미지와 바이트가 같고, 35쪽은 별도로 재확인했다. 표 머리글을 지적했던 14쪽도 실제 PNG의 상단을 추출해 다시 확인했으며 머리글이 정상적으로 반복된다.

페이지 밖 잘림, 한글·그림 누락, 제목 고립, 비정상 빈 페이지는 확인되지 않았다. 표의 행 유지와 열 너비를 조정했고, Word 제목·머리글 스타일도 확인했다. 편집기·폰트 환경이 다르면 페이지 수와 줄바꿈은 달라질 수 있다.

## 검증 범위

이 저장소에는 아직 제품 코드·확정 계약·확정 ADR·실행 가능한 check-all이 없다. 제품 빌드, 보안 구현, 실제 계정 로그인·발송·업로드 시험은 수행하지 않았다. 외부 근거는 요건서 17.4의 서버 업로드 관련 공식 문서를 확인했으며, 이전 판에서 이어받은 다른 서비스 정책을 모두 재검증했다고 표시하지 않았다.
