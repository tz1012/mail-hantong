# v2.2 문서 검증 결과

검증일: 2026년 10월 29일. 대상은 이 폴더의 Word 요건서와 개발 문서다. 문서 검증 결과이며, 제품 구현이나 실제 메일 서비스 시험의 통과를 뜻하지 않는다.

`validate_documents.py`를 실행해 위 항목을 확인했다. Python 환경에 `python-docx`가 필요하다. 기본 실행은 읽기 전용이며, `--write-index`를 지정할 때만 요건 색인을 재생성한다.

```powershell
python .\docs\revisions\v2.2\validate_documents.py
```

## 내용 검토

예약 시각·초안 버전·그룹 수신자 스냅샷의 승인 결속, 예약 수정·취소 경합, 만료 승인과 SEND_UNKNOWN 처리를 검토했다. 폴더 삭제는 보존 이동과 빈 폴더 확인 후에만 가능하며, 새 메일 유입 경합에서 무손실을 보장하지 못하면 거부하도록 명확히 했다.

규칙의 발송·전달·계정 간 자료 전송 금지, 신규·기존 메일의 모든 대량 변경에 대한 새 승인, 분할 배치 우회 방지 문구를 일치시켰다. 광고 오탐 복원과 주소록 범위도 검토했다. 이 검토는 구현 계약이나 보안 구현에 대한 사람 승인을 대신하지 않는다.

## Word 시각 검수

Microsoft Word에서 읽기 전용으로 열어 페이지를 다시 계산하고 PDF로 내보냈다. 패키지의 `render_docx.py`에 이 PDF와 번들 Poppler를 연결해 원본 크기의 페이지 이미지를 생성했다. 최종 문서는 93쪽이다.

초기 94쪽을 전부 시각 검수한 뒤, 마지막 참고문헌의 제목·URL을 함께 배치하고 간격을 조정해 한 쪽을 줄였다. 최종 렌더의 1~92쪽은 검수한 이미지와 바이트 단위로 동일하며, 변경된 93쪽은 다시 열어 확인했다. 표의 반복 머리글, 한글 표시, 도해, 새 요건 행, 추가 수용시험의 번호를 확인했고 잘림·겹침·누락을 발견하지 못했다.

최종 Word SHA-256:

```text
d7d9818c0e277d23cf06a950ea7f412636142212a1875680270147ab3d342f35
```

## 남은 구현 검증

요건↔카드 연결은 구현 시험의 증거가 아니다. 수용기준별 테스트, 제공자별 지원 검증, 실제 계정의 사람이 수행하는 검증, 계약·ADR·보안 구현 검토는 해당 작업 카드에서 진행한다. 이번 문서 개정에서는 제품 코드를 변경하거나 실제 계정에 접속하지 않았다.
