# 기본 메일 기능을 반영한 v2.2 개정안

예약메일함, 폴더, 태그, 기본 자동화, 즐겨찾기, 스팸함, 광고필터, 임시보관함, 로컬 주소록을 모두 1단계 필수 기능(P0)으로 반영했다. 사용자는 2026년 10월 29일 “기본 기능은 모두 1단계 필수로 포함”을 선택했다. 이 범위 결정은 확인된 요구사항이며, 개별 기술·계약·보안 구현의 승인을 뜻하지 않는다.

기존 v2.0 원본과 v2.1 개정본은 보존했다. 총 요건은 161개에서 167개로 늘었고, 1단계 P0 요건은 141개다. 기존 ID는 유지했으며 MAIL-13과 AI-12의 우선순위만 P1에서 P0로 바꿨다. 신규 ID는 MAIL-17~22다.

활성 작업 카드는 147개이며 모두 미착수다. 구현 완료·시험 통과·사람 검토 승인 기록을 만들지 않았다. 문서상 요건↔카드 연결은 [요건 색인](requirements-index.csv), 진행 상태는 [상태장부](card-status.csv)에서 확인한다.

## 적용 상태

v2.1의 [검토할 결정](../v2.1/REVIEW.md)은 계속 유효하다. 이번에 확인한 기능 범위를 바탕으로 계약 초안을 작성하고, 해당 검토 절차를 거쳐 구현한다. 루트 AGENTS.md와 확정된 기준 문서를 자동 교체하지 않았다.

광고필터는 로컬 분류·오탐 복구를 기본으로 하고, 주소록은 로컬 연락처·그룹 관리까지 포함한다. 외부 주소록 동기화, 외부 AI 기반 광고 분류, 임의 코드 실행 자동화, 자동 구독 해지는 이번 기본 범위가 아니다.
