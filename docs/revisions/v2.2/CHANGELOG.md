# v2.2 변경 내역

사용자 요청에 따라 기본 메일 기능 9종을 1단계 필수로 구체화했다. 원본과 v2.1 개정본은 보존했다.

- **우선순위 변경:** MAIL-13 예약 발송, AI-12 기본 규칙 자동화를 P1에서 P0로 승격. 단계는 그대로 유지한다.
- **새 요건 6개:** MAIL-17 폴더 관리, MAIL-18 태그, MAIL-19 즐겨찾기, MAIL-20 스팸함, MAIL-21 광고 분류, MAIL-22 로컬 주소록. 모두 P0·1단계다.
- **기존 요건 보강:** MAIL-01 보기 구성, MAIL-03 검색, MAIL-08 임시보관함, EXT-06 스팸 폴더 매핑, AI-09 예약 시각·그룹 수신자 결속, PUSH-09 자동 에이전트 실행의 제한.
- **계약 요구 보강:** 예약·태그·고정 보기·분류·연락처 모델, 폴더/태그/주소록 관리와 예약·규칙 도구의 논리 목록. 실제 계약 승인 전 구현 금지는 유지한다.
- **수용시험 추가:** 26 정리, 27 스팸·광고, 28 주소록, 29 초안·예약, 30 자동화. 모두 Gate 1에 포함한다.
- **계획 변경:** M4·M5·M6·M8·M9에 카드 14개 추가. M10-01 예약 발송은 M5-11·12, M10-02 기본 규칙은 M6-11·12로 이관하고 기록을 남겼다. M10에는 남은 P1 확장만 둔다.

요건은 167개, 활성 카드는 147개다. 이관된 두 카드 ID는 재사용하지 않는다. 카드 상태는 모두 미착수이며 개별 수용기준·계약·보안 검토의 완료를 선언하지 않는다.

안전 조건도 함께 적었다. 폴더 삭제의 새 메일 유입 경합, 태그 삭제와 원문 보존, 예약 취소와 실행의 경합, 규칙의 반복·순환·한도 우회, 광고 오탐, 관측 주소 위조와 그룹 수신자 변경을 시험한다. 모든 외부 발송은 사람 승인과 내용 결속을 유지한다.
