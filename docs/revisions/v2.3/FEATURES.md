# mail-hantong 1단계 필수 범위

제품·솔루션 이름은 `mail-hantong`, CLI 명령은 `hantong`이다. 아래 지원 조건도 처음부터 P0로 제공한다.

| 지원 조건 | 요건 | 완료 기준 |
| --- | --- | --- |
| GUI 한국어·영어 | OPS-07, OPS-02 | 첫 화면부터 양 언어 리소스, 런타임 전환, 초안·계정·승인 상태 보존, 접근성 이름·오류·도움말 포함 |
| 라이트·다크·시스템 | OPS-08, OPS-02 | 기본 system, OS 실시간 변경 추종, 명시 테마 유지, 대비 테마 우선, 선택 저장·재시작 및 모든 앱 창 검증 |
| CLI 영어 기본 지원 | CLI-16, CLI-01·02·07 | 영어 기본 도움말·오류·설정·진단, 한국어 선택, 안정적인 기계 출력·종료 코드, UTF-8 데이터 보존 |

[UX/UI 가이드](../../../DESIGN.md)와 [버전 보관본](DESIGN.snapshot.md)에 참고 저장소의 적용 방향과 세부 기준을 기록했다.

## 기본 메일 기능

아래 9개 기본 기능은 모두 P0다. 예약 발송과 기본 규칙 자동화도 Gate 1 전에 구현·검증한다.

| 기능 | 요건 | 포함하는 기본 동작 | 구분할 사항 |
| --- | --- | --- | --- |
| 예약메일함 | MAIL-13, AI-09 | 예약 목록, 계정·시각·시간대·승인·실행 상태, 수정·취소, 실패 확인 | 시각·내용 변경은 재승인. PC가 꺼져 있으면 정시 발송 보장 없음. SEND_UNKNOWN 자동 재발송 금지 |
| 폴더 | MAIL-17, EXT-06 | 계정별 트리, 생성·이름 변경, 지원되는 계층 이동, 안전한 삭제 | 시스템 폴더 보호. 내용·하위 폴더 손실 또는 새 메일 유입 경합을 막지 못하는 삭제는 거부 |
| 태그 | MAIL-18 | 생성·이름·색상·삭제, 메일 다중 적용·해제·검색 | 로컬 태그와 서버 라벨의 범위·동기화를 구분. 태그 삭제로 메일 삭제 금지 |
| 기본 자동화 | AI-12, PUSH-09 | 조건 편집, dry-run, 사람 검토 후 활성화, 순서·중단·한도·만료·일시정지·이력 | 저장된 결정적 규칙과 AI 에이전트 자동 실행을 구분. 자동 발송·전달은 금지. 스팸·휴지통·대량 작업은 새 승인 |
| 즐겨찾기 | MAIL-19 | 메일 별표와 모아보기, 폴더·태그 메뉴 고정·정렬 | 메일 즐겨찾기와 탐색 메뉴 고정은 별도. 해제 시 메일·폴더 유지 |
| 스팸함 | MAIL-20 | 계정별 목록·검색, 스팸 지정·정상 복원 | 단순 이동과 제공자 신고 효과 표시. 원래 위치 또는 같은 계정의 선택 위치로 복원 |
| 광고필터 | MAIL-21 | 광고/프로모션 보기, 로컬 규칙, 분류 이유·버전·예외, 오탐 해제 | 기본은 원본 위치 유지. 광고와 스팸 구분. 자동 삭제·URL 호출·구독 해지 없음 |
| 임시보관함 | MAIL-08 | 목록·재편집, 자동 저장, 첨부 복구, 충돌 상태, 안전한 폐기 | 예약 연결 초안 변경·폐기는 예약/승인을 무효화. 복구 자체로 발송되지 않음 |
| 주소록 | MAIL-22 | 연락처·복수 주소·메모·그룹 CRUD, 검색·자동완성 | 계정 전용/사용자 공용 범위, 관측 주소와 저장 연락처 구분, 그룹 주소를 확정해 발송 검토 |

모든 경로는 같은 코어의 계정 범위·권한·버전·승인 검사를 사용한다. 제공자별 지원 차이는 capability로 표시하고, 없는 서버 기능을 지원하는 것처럼 표시하지 않는다.

확장은 별도 요건으로 다룬다. 예를 들어 Google·Microsoft 주소록 동기화, 주소록 파일 대량 가져오기·내보내기, 외부 AI 광고 분류, 임의 스크립트·웹훅 자동화는 위 기본 기능에 포함하지 않는다. 저장된 연락처가 있다는 이유만으로 발신자를 신뢰하거나 안전 검사를 생략하지 않는다.
