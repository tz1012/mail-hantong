## 내용 검토

GUI·승인 도우미의 첫 화면부터 양 언어·세 테마를 적용하고, CLI 첫 골격부터 영어 리소스를 제공하도록 요건과 카드에 연결했다. CLI 언어는 명시 옵션 → 저장된 cli.language → 영어 순서이며 GUI 언어와 독립적이다. JSON/NDJSON 키·상태·오류·종료 코드가 번역되지 않도록 명시했다.

OS 테마 추종, 명시 테마 유지, Windows 대비 테마 우선순위, 언어·테마 전환 중 초안과 승인 요청 보존을 검토했다. 승인 안내 문구와 승인에 결속된 원문·주소를 구분해 전자는 번역하고 후자는 보존하도록 정리했다. M9-20은 가짜 제공자를 사용하되 OS 언어·테마 전환은 실제 Windows UI 환경에서 시험한다.

## Word 검수

Microsoft Word에서 읽기 전용으로 열어 페이지를 다시 계산하고 PDF로 내보냈다. 패키지의 render_docx.py에 이 PDF와 번들 Poppler를 연결해 97쪽의 원본 크기 PNG를 생성했다. 1~32쪽, 33~64쪽, 65~97쪽으로 나누어 모든 페이지를 시각 검수했다.

표의 반복 머리글, 글자·행 경계, 도해, 명령 예제, 새 요건과 수용시험, 마지막 참고 자료를 확인했다. 반복 이미지 표시에서 생략돼 보였던 머리글은 실제 PNG 상단을 별도 추출해 정상 렌더를 확인했다. 잘림·겹침·누락은 발견하지 못했다.


## 이후 구현에서 확인할 사항

번역 문장 품질, 화면별 레이아웃·대비·접근성, 운영체제 전환, 실제 CLI 출력은 아직 구현 시험을 수행하지 않았다. 계약·ADR·제품 코드를 구현하는 각 카드에서 이 검증을 진행한다. 참고 사이트의 기술 스택이나 외부 자산을 도입하지 않았으며, 문서의 연결 검증을 구현 완료로 기록하지 않았다.
