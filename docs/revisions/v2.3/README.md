# mail-hantong v2.3 개정안

응용프로그램·솔루션 이름은 **mail-hantong**, CLI 명령은 **hantong**으로 정했다. GUI는 첫 제작부터 한국어·영어와 라이트·다크·시스템 테마를 제공하고, CLI도 첫 구현부터 영어를 기본 지원한다. 사용자가 지정한 세 저장소를 참고한 UX/UI 가이드도 추가했다.

## 핵심 동작

- GUI는 `한국어 / English`를 선택하고 실행 중 변경할 수 있다. 초안·첨부·선택·승인 요청을 보존한다.
- 테마는 `light / dark / system`이며 기본은 `system`이다. 시스템 선택 시 실행 중 OS 테마 변경을 따라간다. Windows 대비 테마에서는 시스템 색을 우선한다.
- CLI는 영어 기본 출력과 한국어 선택을 제공한다. 도움말·오류·설정·진단·승인 대기 안내도 포함한다. `--lang en|ko` → `cli.language` → `en` 순서로 적용한다.
- 명령·옵션, JSON/NDJSON 키, 오류·상태·종료 코드와 MCP `mail.*` 식별자는 번역하지 않는다.

기존 167개 요건을 유지하고 OPS-07·08, CLI-16을 추가해 총 170개다. 기존 우선순위·단계는 그대로이며 1단계 P0는 144개다. 기존 CLI-15와 M1-11의 ID를 재사용하지 않고 새 영어 지원 카드는 M1-12로 배정했다. 활성 카드 151개는 모두 미착수다.

## 적용 상태

이름과 필수 언어·테마 범위는 사용자 요청을 반영했다. GUI 프레임워크·구체 색상값·계약 스키마는 해당 ADR·계약 검토를 거쳐 확정한다. v2.2 이전 파일과 루트의 기존 문서는 보존했으며, 루트에 `DESIGN.md`를 새로 추가했다.

`docs/requirements/`, `docs/plan/`, `docs/contracts/` 경로는 채택 후 사용할 구조다. 현재 개정안의 기준 문서와 상태장부는 이 폴더에 있다. v2.1의 [미결 검토 항목](../v2.1/REVIEW.md)은 계속 유효하며, 이번에 확정한 명칭·언어·테마 범위를 다시 미결 사항으로 취급하지 않는다.

[검증 스크립트](validate_documents.py), [요건 전후 비교](requirements-changes.json), [보존 파일 체크섬](source-files.sha256)을 함께 제공한다. 문서 검증은 제품 구현·실제 계정 시험의 통과를 뜻하지 않는다.
