검토용 수용기준 후보: AC 식별자는 원문 문장 경계에 부여했다. 설명·원문 전체·단계·조건·예외를 함께 해석한다. 복합 항목과 단계별 적용 범위는 검토가 남아 있다. AC 개수는 독립 시험 수 또는 구현 완료 수가 아니다.

- **ACC-02-AC01** 잘못된 state, 만료된 로그인 요청, 중복 콜백은 거부된다.
- **ACC-02-AC02** 앱에 포함되는 공개 클라이언트 값은 비밀로 간주하지 않는다.

- **ACC-04-AC01** 쓰기 권한을 거부해도 가능한 읽기 기능은 유지된다.
- **ACC-04-AC02** 읽기 전용 계정은 UI·검색·AI 선택 화면에 표시하고 서버 초안·라벨·발송을 차단한다.
- **ACC-04-AC03** 기존 권한이 넓어도 앱 정책은 동일하게 강제한다.
