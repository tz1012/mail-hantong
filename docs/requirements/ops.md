### 원문 설명

- **OPS-01-AC01** 성능 목표 미달 원인과 계정별 자원 사용량을 기록하고, 대량 메일 처리 중에도 UI가 멈추지 않는다.

### 원문 설명

한국어·영어 메일, 고DPI, 키보드 탐색, 화면 읽기 도구와 확대 표시를 지원한다. GUI 언어는 OPS-07, 라이트·다크·시스템 및 대비 테마는 OPS-08을 따른다. 계정 번호 배지를 쓰며 색상만으로 구분하지 않는다. 한글 IME(KEY-05)와 단일 키 끄기(KEY-09)를 포함한다.

### 수용 기준 후보

> 원문 수용 기준 전체: 두 언어와 각 테마에서 키보드만으로 계정 선택→검색→초안→발송 검토를 끝낸다. 150%·200% 배율에서 핵심 버튼·경고가 잘리지 않는다. 일반 텍스트 4.5:1, 큰 텍스트·UI 상태 경계 3:1 대비를 시험한다.

검토용 수용기준 후보: AC 식별자는 원문 문장 경계에 부여했다. 설명·원문 전체·단계·조건·예외를 함께 해석한다. 복합 항목과 단계별 적용 범위는 검토가 남아 있다. AC 개수는 독립 시험 수 또는 구현 완료 수가 아니다.

적용 범위 검토: 언어·테마·배율·대비 대상의 시험 조합을 검토한다. 문장 수는 시험 수가 아니다.

- **OPS-02-AC01** 두 언어와 각 테마에서 키보드만으로 계정 선택→검색→초안→발송 검토를 끝낸다.
- **OPS-02-AC02** 150%·200% 배율에서 핵심 버튼·경고가 잘리지 않는다.
- **OPS-02-AC03** 일반 텍스트 4.5:1, 큰 텍스트·UI 상태 경계 3:1 대비를 시험한다.
