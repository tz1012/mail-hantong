## SEC-01 비밀 저장소

- 우선순위: `P0`  
- 단계: `1`  
- 작업 카드: `M1-03`  
- 원문 위치: [T20-R2-SEC-01](source-content.md#T20-R2-SEC-01)

### 원문 설명

Windows 보호 저장소 또는 동등한 OS 보안 기능으로 계정 토큰·외부 서버 앱 비밀번호·모델 API 키를 보호한다. 저장소는 일반 메일 DB·설정·로그·백업과 분리한다.

### 수용 기준 후보

> 원문 수용 기준 전체: 평문 토큰이 파일·로그·오류 보고서·CLI·MCP 응답에 나타나지 않는다. Windows 사용자 A의 비밀을 B가 정상 앱 경로로 읽을 수 없다.

검토용 수용기준 후보: AC 식별자는 원문 문장 경계에 부여했다. 설명·원문 전체·단계·조건·예외를 함께 해석한다. 복합 항목과 단계별 적용 범위는 검토가 남아 있다. AC 개수는 독립 시험 수 또는 구현 완료 수가 아니다.

- **SEC-01-AC01** 평문 토큰이 파일·로그·오류 보고서·CLI·MCP 응답에 나타나지 않는다.
- **SEC-01-AC02** Windows 사용자 A의 비밀을 B가 정상 앱 경로로 읽을 수 없다.

- **SEC-02-AC01** 키 없는 DB 파일 복사본에서 원문을 읽을 수 없는 구성을 기본안으로 시험한다.
- **SEC-02-AC02** 검색 색인과 임시 추출물도 같은 보호 정책을 따른다.

## SEC-03 로컬 접근 통제

- 우선순위: `P0`  
- 단계: `1`  
- 작업 카드: `M0-05,M1-02,M1-09,M6-02`  
- 원문 위치: [T20-R4-SEC-03](source-content.md#T20-R4-SEC-03)

### 원문 설명

사용자 ACL이 적용된 로컬 IPC를 사용하고 MCP는 기본 stdio다. ACL에 더해 등록된 호출 주체·세션을 인증한다. HTTP는 loopback·인증·Origin·DNS rebinding 방어를 적용한다. 구체 인증 수단은 ADR와 IPC 계약으로 확정한다.

### 수용 기준 후보

> 원문 수용 기준 전체: 임의 웹페이지·다른 사용자·무인증 프로세스·미등록 클라이언트의 메일 접근을 차단한다. 동일 사용자 프로세스라도 이름·TTY·자기 선언 client_id만으로 권한을 얻지 못한다. 경계와 한계는 7.3에 기록한다.

검토용 수용기준 후보: AC 식별자는 원문 문장 경계에 부여했다. 설명·원문 전체·단계·조건·예외를 함께 해석한다. 복합 항목과 단계별 적용 범위는 검토가 남아 있다. AC 개수는 독립 시험 수 또는 구현 완료 수가 아니다.

- **SEC-03-AC01** 임의 웹페이지·다른 사용자·무인증 프로세스·미등록 클라이언트의 메일 접근을 차단한다.
- **SEC-03-AC02** 동일 사용자 프로세스라도 이름·TTY·자기 선언 client_id만으로 권한을 얻지 못한다.
- **SEC-03-AC03** 경계와 한계는 7.3에 기록한다.

## SEC-04 파일과 네트워크 권한

- 우선순위: `P0`  
- 단계: `1`  
- 작업 카드: `M4-13`  
- 원문 위치: [T20-R5-SEC-04](source-content.md#T20-R5-SEC-04)

### 원문 설명

첨부는 허용 경로·안전한 캐시에서만 처리하고 추출기를 격리하며 크기·시간·압축 해제량을 제한한다. 제품의 AI 도구는 임의 파일·셸·URL 요청을 제공하지 않는다. 외부 에이전트 호스트 전체의 OS 권한을 제품이 통제한다고 가정하지 않으며, 별도 권한이 있어도 IPC·계정·승인 검사를 우회할 수 없어야 한다.

### 수용 기준 후보

> 원문 수용 기준 전체: 경로 탈출·심볼릭 링크·UNC 경로·로컬 서비스 접근 시도를 검사하고 차단한다. 문서 매크로와 첨부 실행은 자동 수행되지 않는다.

검토용 수용기준 후보: AC 식별자는 원문 문장 경계에 부여했다. 설명·원문 전체·단계·조건·예외를 함께 해석한다. 복합 항목과 단계별 적용 범위는 검토가 남아 있다. AC 개수는 독립 시험 수 또는 구현 완료 수가 아니다.

- **SEC-04-AC01** 경로 탈출·심볼릭 링크·UNC 경로·로컬 서비스 접근 시도를 검사하고 차단한다.
- **SEC-04-AC02** 문서 매크로와 첨부 실행은 자동 수행되지 않는다.
