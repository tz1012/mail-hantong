- 작업 카드: `M2-05`

### 원문 설명

- **SYNC-01-AC01** 대용량 계정에서도 첫 목록을 보기 위해 전체 첨부 다운로드 완료를 기다리지 않는다.
- **SYNC-01-AC02** 남은 범위와 일시정지 상태를 표시한다.

## SYNC-07 발송 불확실성과 중복 방지

- 단계: `1`  
- 작업 카드: `M4-08,M5-12`  
- 원문 위치: [T12-R8-SYNC-07](source-content.md#T12-R8-SYNC-07)

### 원문 설명

발송 의도 ID, 승인한 내용 해시, 생성한 Message-ID, 시도 이력을 로컬 원장에 저장한다. 타임아웃·응답 유실은 "상태 불명"(SEND_UNKNOWN)으로 두고 보낸편지함을 재조회한다.

### 수용 기준 후보

> 원문 수용 기준 전체: 서버 접수 후 응답만 잃은 시나리오에서 자동 재발송하지 않는다. 확인할 수 없으면 사용자에게 중복 위험을 알리고 재시도 승인을 받는다. 제공자 API의 완전한 exactly-once를 가정하지 않는다.

검토용 수용기준 후보: AC 식별자는 원문 문장 경계에 부여했다. 설명·원문 전체·단계·조건·예외를 함께 해석한다. 복합 항목과 단계별 적용 범위는 검토가 남아 있다. AC 개수는 독립 시험 수 또는 구현 완료 수가 아니다.

적용 범위 검토: 불명 상태 확인·사람 재시도 승인과 자동 재발송 금지를 함께 검토한다.

- **SYNC-07-AC01** 서버 접수 후 응답만 잃은 시나리오에서 자동 재발송하지 않는다.
- **SYNC-07-AC02** 확인할 수 없으면 사용자에게 중복 위험을 알리고 재시도 승인을 받는다.
- **SYNC-07-AC03** 제공자 API의 완전한 exactly-once를 가정하지 않는다.
